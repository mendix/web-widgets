## Summary

The Tiptap migration (5.0.0) left the runtime contract with Mendix under-tested and several behaviours silently broken. The worst confirmed issue is BEH-17: with `styleDataFormat = "class"` (strict CSP), color, font family and font size are lost when saved content is loaded again. Four XML properties (`spellCheck`, `linkValidation`, `defaultFontFamily`, `defaultFontSize`) do nothing (BEH-04..06), and read-only changes after mount never apply (BEH-02). Toolbar keyboard accessibility is incomplete. Unit-test coverage is done (mendix/web-widgets#2453); those tests confirmed BEH-02, BEH-12 and BEH-15 and found BEH-17..19. BEH-01 was a false positive (see Notes). Fix next: the small, independent bugs (BEH-17, 02, 03, 11, 18, 15, 19), each with a regression test. BEH-04..06 need a product decision (restore or remove), which also blocks DOCS-01.

## Notes

- The SMELL agent also reported the 4 unused XML properties; they are tracked once, as BEH-04..06, to avoid double counting. The fullscreen multi-instance bug was moved from SMELL to BEH-11.
- PERF-03 was confirmed by reading `useDebounceWithStatus` in `packages/shared/widget-plugin-hooks`. That shared hook is not wrong for its intended use; the widget passes `isExecuting=false`, which disables debouncing. No shared-package change is proposed.
- BEH-01 is a **false positive** (status `stale`): `@tiptap/react` registers wrappers that call `this.options.current.onUpdate/onBlur/…`, and `options.current` is refreshed every render (`node_modules/@tiptap/react/dist/index.js:318-374`), so `useEditor(..., [])` callbacks always run the latest closure. Verified on 2026-10-06 with regression tests (rerender with a new attribute and new ActionValues) that pass with and without the proposed fix. Those tests are still useful for UT-01/UT-02.
- BEH-04..06 and DOCS-01 need a product decision: restore the 4 lost properties, or remove them from the XML (breaking: stored values disappear, so it needs a major or a clear changelog note).
- Local `node_modules` is stale versus `package.json` (e.g. `@tiptap/*` installed 3.29.0, declared ^3.31.3). Run `pnpm install` before Phase 2 verification.
- E2E: `mxcli` exists, but there is no local test project (`tests/` missing). The page inventory was inferred from specs; it is unconfirmed whether pages exist for focused dialogs, `onChange` counters, `imageSource` or `helpButton=false`. Most E2E-High fixes need test-project edits (`mendix:edit-test-project` skill).
- No tests, builds or e2e runs were executed in Phase 1.
- BEH-17..19 were not in the original audit; the UT tests found them. The original read-only audit also missed BEH-17, the most severe issue, so fixes should start from a failing test rather than from the audit text alone.
