# Switch

Toggle a boolean attribute

## Overview

- **Folder**: `switch-web`
- **Category**: Input elements
- **Offline capable**: Yes
- **Reference**: [Mendix documentation](https://docs.mendix.com/appstore/widgets/switch)

## XML Properties

### Data source

- **Boolean attribute** (`booleanAttribute`; type: attribute). Attribute to toggle Attribute types: Boolean.

### Actions

- **On change** (`action`; type: action, optional). Action to be performed when the switch is toggled

- **Label**. Standard Mendix system property.
- **Editability**. Standard Mendix system property.
