# Fieldset

A container to group several controls within a web form

## Overview

- **Folder**: `fieldset-web`
- **Category**: Input elements
- **Offline capable**: Yes
- **Reference**: [Mendix documentation](https://docs.mendix.com/appstore/widgets/fieldset)

## XML Properties

### General

- **Legend** (`legend`; type: textTemplate, optional).
- **Content** (`content`; type: widgets).

### Visibility

- **Visibility**. Standard Mendix system property.

### Common

- **Name**. Standard Mendix system property.
- **TabIndex**. Standard Mendix system property.

## Additional Notes

Please see [Fieldset](https://docs.mendix.com/appstore/widgets/fieldset) in the Mendix documentation for details.
