# Charts

Chart widgets collection for data visualization

## Overview

- **Folder**: `charts-web`
- **Type**: Widget bundle
- **Contained widget definitions**: 10

## Included Widgets

- area-chart
- bar-chart
- bubble-chart
- chart-playground
- column-chart
- custom-chart
- heatmap-chart
- line-chart
- pie-doughnut-chart
- time-series-chart

## XML Coverage

This package references multiple widget XML files through its package definition instead of exposing a single widget XML surface in this folder. See the individual widget package READMEs for per-widget property details.

## Additional Notes

This is the package being used to automate the release of Data Widgets module.
