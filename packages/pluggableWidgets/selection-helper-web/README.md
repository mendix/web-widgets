# Selection helper

Makes it easier for users to select multiple items in Gallery widget.

## Overview

- **Folder**: `selection-helper-web`
- **Category**: Data controls
- **Offline capable**: Yes
- **Reference**: [Mendix documentation](https://docs.mendix.com/appstore/modules/gallery#selection-helper-widget)

## XML Properties

- **Style** (`renderStyle`; type: enumeration, default: checkbox). Custom enables placeholders for using widgets for the different states. Allowed values: `checkbox` (Check box), `custom` (Custom).
- **Check box caption** (`checkboxCaption`; type: textTemplate, optional).
- **All selected** (`customAllSelected`; type: widgets).
- **Some selected** (`customSomeSelected`; type: widgets).
- **None selected** (`customNoneSelected`; type: widgets).

## Additional Notes

Please see [Selection helper](https://docs.mendix.com/appstore/modules/gallery#selection-helper-widget) in the Mendix documentation for details.
