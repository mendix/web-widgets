# Rating

Displays a rating mechanism with icons

## Overview

- **Folder**: `rating-web`
- **Category**: Display
- **Offline capable**: Yes
- **Reference**: [Mendix documentation](https://docs.mendix.com/appstore/widgets/rating)

## XML Properties

- **Attribute** (`rateAttribute`; type: attribute). Attribute types: Integer, Long, Decimal.
- **Empty icon** (`emptyIcon`; type: icon, optional).
- **Selected icon** (`icon`; type: icon, optional).
- **Amount** (`maximumStars`; type: integer, default: 5). The number of rating icons
- **Animation** (`animation`; type: boolean, default: true).
- **On change** (`onChange`; type: action, optional).
- **Name**. Standard Mendix system property.
- **Editability**. Standard Mendix system property.
- **Visibility**. Standard Mendix system property.
- **TabIndex**. Standard Mendix system property.
