# Carousel

Carousel displaying images

## Overview

- **Folder**: `carousel-web`
- **Category**: Display
- **Offline capable**: Yes

## XML Properties

### Data Source

- **Data source** (`dataSource`; type: datasource, optional, list).
- **Content** (`content`; type: widgets, optional, data source: dataSource).

### Display

- **Pagination** (`showPagination`; type: boolean, default: true).
- **Navigation controls** (`navigation`; type: boolean, default: true).
- **Auto play** (`autoplay`; type: boolean, default: false).
- **Delay** (`delay`; type: integer, default: 1000). The amount of time to delay between automatically cycling an item (ms)
- **Infinite loop** (`loop`; type: boolean, default: true).
- **Animation** (`animation`; type: boolean, default: true).

### Events

- **On click action** (`onClickAction`; type: action, optional).
