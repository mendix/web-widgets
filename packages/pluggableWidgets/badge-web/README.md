# Badge

Shows a value inside a colored badge or label

## Overview

- **Folder**: `badge-web`
- **Category**: Display
- **Offline capable**: Yes
- **Reference**: [Mendix documentation](https://docs.mendix.com/appstore/widgets/badge)

## XML Properties

### General

- **Type** (`type`; type: enumeration, required, default: badge). Render it as either a badge or a color label Allowed values: `badge` (Badge), `label` (Label).
- **Value** (`value`; type: textTemplate, optional).

### Events

- **On click** (`onClick`; type: action, optional).

### Visibility

- **Visibility**. Standard Mendix system property.

### Common

- **Name**. Standard Mendix system property.
- **TabIndex**. Standard Mendix system property.
